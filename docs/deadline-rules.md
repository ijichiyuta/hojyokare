# 期限ルール検証結果(2026-08-16 Web調査+公式PDF原本確認)

デザインモックのルールと実際の制度の突合結果。エンジン(`src/lib/subsidy/`)はこの内容に準拠。
**報告ルール(実績報告・事業化状況報告・財産処分)は公式PDF原本で確認済み**。
公募回ごとの実施期間の月数は第13回(事業再構築)・第19次(ものづくり)を原本確認済み(`verified: true`)、
他回は同一パターンの適用(該当回の公募要領での個別確認が残り、`verified: false`)。
実際の期限は交付決定通知書・事務局通知が優先のため、UIの「目安」表示は今後も維持する。

## 原本確認結果(2026-08-16、引用)

### 事業再構築補助金

- **実績報告** — 補助事業の手引き(第6〜9回向け 2.0版)「(18)実績報告書(交付規程第17条)」:
  > 補助事業が完了(廃止の承認を受けた場合を含む。)したときは、その日から起算して30日を経過した日又は補助事業完了期限日のいずれか早い日までに(中略)提出してください。
- **事業化状況報告** — 事業化状況報告システム操作マニュアル 3.4版:
  > 初回は、原則、補助事業終了年度の決算日の3か月後、2回目以降は、その翌年度から毎年の決算日の3か月後までに報告いただきます。
  > 補助事業の完了日が属する年度の終了後を初回として、以降5年間、毎年の決算日の3か月後までに「事業化状況・知的財産権等報告書」(様式第13)(以下略)
  ※手引き側は事業計画期間を「補助事業**完了期限日**の属する決算年度から5年間」と定義。完了日と完了期限日が別年度になる場合は初回年度がずれうる(チェッカーは終了予定日基準で近似)
- **実施期間** — 第13回公募要領 1.0版: 成長分野進出枠(通常類型)・コロナ回復加速化枠「交付決定日〜12か月以内(ただし採択発表日から14か月後の日まで)」、GX進出類型「14か月以内(16か月後まで)」
- **財産処分** — 補助事業の手引き: 処分制限期間は「減価償却資産の耐用年数等に関する省令(昭和40年大蔵省令第15号)」の耐用年数を準用

### ものづくり補助金

- **実績報告** — 補助事業の手引き(19次締切 1.0版):
  > 本事業を完了したときは、その日から起算して30日を経過した日又は事業完了期限日のいずれか早い日(以下略)
- **事業化状況報告** — 同手引き:
  > 補助金全額の交付を受けた日(※)以降、最初に迎える4月1日から60日以内の日を初回として、以降5年間(合計6回)(中略)報告するとともに(以下略)
  > (※)具体的には「補助金の額の確定通知」を2月末までに受領した事業者の方が対象となります。
  ※つまり期限は毎年5/31。額確定が3/1以降の場合は初回が1年繰り下げ。チェッカーは受領日を入力に持たないため終了予定日で近似(注記表示あり)
- **実施期間** — 第19次公募要領: 製品・サービス高付加価値化枠「交付決定日から10か月(ただし採択発表日から12か月後の日まで)」、グローバル枠「12か月(14か月後まで)」
- **第23次公募の存在確認**: 公募期間 2026/2/6〜5/8(公式サイト掲載の公募要領) → マスタに追加済み

## 確定したルール

### 事業再構築補助金

| 項目 | ルール | モックとの差分 |
|------|--------|----------------|
| 補助事業完了期限 | 交付決定日から12ヶ月(グリーン成長枠14ヶ月) | 一致 |
| 実績報告 | 完了日から30日を経過した日 **または補助事業完了期限日のいずれか早い日** | キャップの実装が必要だった(対応済み) |
| 事業化状況報告 | 初回=補助事業終了年度の決算日の3ヶ月後、以降毎年決算日+3ヶ月。**初回+5年間=合計6回** | **モックは5回(1〜5年目)表示 → 誤り。6回が正** |
| 財産処分制限 | 正式には資産(50万円以上の建物・機械等)ごとに法定耐用年数を準用。耐用年数5年以下でも終了年度末から5年間の保管義務 | モックの「終了日から一律5年」は目安として妥当だが注記が必要(対応済み) |

### ものづくり補助金

| 項目 | ルール | モックとの差分 |
|------|--------|----------------|
| 補助事業実施期間 | 通常は交付決定日から10ヶ月。**18次は特例で2024/12/10まで固定(実績報告含む・延長不可)** | モックに定義なし → 固定期限型をマスタに追加 |
| 事業化状況報告 | 補助事業終了後5年間・**合計6回**。報告期間は**毎年4月1日〜5月31日**(決算月に依存しない)。初回は補助金受領後の最初の報告期間 | **モックの「決算日+3ヶ月」型とは別ルール** → fixedWindow 型をマスタに追加 |

## エンジンへの反映(実装済み)

- `JigyoukaRule` を判別共用体化: `fiscalYearEnd`(事業再構築型)/ `fixedWindow`(ものづくり型)
- 実績報告に完了期限日キャップ(`min(終了予定日+30日, 完了期限日)`)
- 完了期限に固定日(`completionDeadlineFixed`)対応(18次特例)
- 事業化状況報告は6回生成、ラベルは「(1回目)〜(6回目)」
- 財産処分制限に「法定耐用年数準用が正式」の注記

## 収録カバレッジ(2026-08-16 拡充)

2026年時点で事業化状況報告の義務が生きている公募回まで収録(計30エントリ)。

- **事業再構築補助金**: 第6回〜第13回。各回とも「グリーン成長枠以外(12ヶ月)/グリーン成長枠(14ヶ月)」、第12・13回は「GX進出類型以外(12ヶ月)/GX進出類型(14ヶ月)」の2択
- **ものづくり補助金**: 第13次〜第22次。第19次以降は「高付加価値化枠(10ヶ月)/グローバル枠(12ヶ月)」の2択、第18次は固定期限 2024/12/10、第17次(省力化オーダーメイド枠)は12ヶ月(要原本確認)

### 収録していないデータ(意図的)

- **公募日程(公募開始・締切・採択発表日)**: チェッカーは交付決定日をユーザー入力で受けるため計算に不要。ただし「採択発表日から◯ヶ月」の副次上限(事業再構築14ヶ月/16ヶ月、ものづくり12ヶ月/14ヶ月)の精密化には採択発表日が必要 → 将来、公募回マスタに採択発表日を追加する拡張候補
- **補助率・上限額などの制度詳細**: 期限管理に不要のため対象外
- **他の補助金(IT導入・小規模持続化・省力化投資など)**: ロードマップの拡張候補。事業化状況報告に類する報告義務があるため同じマスタ構造で追加可能
- **雇用系助成金(厚労省系)**: 報告義務の体系が別物のためスコープ外

## プロダクトへの影響(要対応)

1. **計算結果画面**: 事業化状況報告は6行になる(デザインは5行)
2. **LPコピー「5年 × 6回」**: 実績1回+事業化6回=計7回なので表現の見直し候補(例: 「5年で7回」「最長6年・7回」)
3. **ものづくり案件のチェッカー入力**: 決算月が期限に影響しないため、入力フォームの説明文を制度により出し分ける必要
4. ものづくり初回報告は「補助金受領月」に依存 → チェッカーでは概算である旨を明示(エンジンの note に記載済み)
